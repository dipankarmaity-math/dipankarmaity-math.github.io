The Glyph Keyboard

An Android keyboard with LaTeX support for Mathematicians

This Android keyboard app is designed for Mathematicians. Hold a key for accents, and for its LaTeX suggestions. Type \beta for β, \A for 𝒜 and 𝔸, \infty for ∞. You can, in fact, create your own list of LaTeX suggestions for each key long press. + Many other features you are welcome to figure out. This has been vibe coded using Grok AI
