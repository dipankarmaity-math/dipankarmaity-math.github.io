Getting Started

Installation & Setup

After downloading the Glyph.apk file, follow these steps to enable the keyboard on your Android device:

  • Open the downloaded APK and grant permission to install from unknown sources if prompted.
  • Navigate to Settings > System > Languages & input > On-screen keyboard.
  • Tap Manage on-screen keyboards and toggle Glyph to the ON position.
  • Tap any text field to open your current keyboard, press the keyboard switcher icon (usually at the bottom right), and select Glyph.
Features

LaTeX-Style Shortcuts

Glyph is optimized for mathematical typing without switching layouts. You can trigger standard symbols using backslash commands directly in the main text field:

  • Greek Letters: Type \alpha for α, \beta for β, and \Omega for Ω.
  • Blackboard Bold & Calligraphic: Type \A to access both 𝒜 and 𝔸 via the suggestion bar.
  • Infinity & Operators: Type \infty for ∞, \otimes for ⊗, and \simeq for ≃.

Long-Press Actions

Hold down standard keys to access superscripts, subscripts, common punctuation, and LaTeX.

Productivity

Clipboard History

The keyboard features a persistent clipboard manager designed to span across different applications.

Tap the Clip icon on the top row of the keyboard to open the history panel. This allows you to store and paste multiple mathematical snippets, URLs, or citations sequentially without leaving your current typing context.
